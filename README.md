## Overview

Emergency evacuation planning and crowd dynamics optimization are critical for public safety in indoor environments. This research focuses on advanced computational methods—specifically extending cellular automata models and real-coded evolutionary algorithms—to simulate and optimize pedestrian evacuation processes. 

The codebase builds upon and integrates elements from the research frameworks provided by the **Bio4Res** research group.

---

## Dependencies & Base Framework

This project heavily relies on and extends components from the Bio4Res ecosystem:

* **[Pedestrian Evacuation Optimization Framework](https://github.com/Bio4Res/pedestrian-evacuation-optimization.git)**: Core optimization library for crowd evacuation scenarios.
* Supporting modules utilized include cellular automaton simulation components, environment handlers, and evolutionary algorithm packages (`ea`).
